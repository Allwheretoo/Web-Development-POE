Glow Up & Co. – Beauty Parlour Website

1. Project Overview

Glow Up & Co. is a beauty parlour website designed to showcase beauty services, display images and provide customers with information about the business.

The website uses the slogan “Your Glow Starts Here.”

2. Project Purpose

The purpose of this website is to create an online platform where customers can:

* Learn more about Glow Up & Co.
* View the beauty services offered.
* Browse the gallery.
* Find contact information.
* Submit a booking request through the contact form.

3. Technologies Used

The following technologies were used to develop the website:

* HTML: Used to create the structure and content of the website.
* CSS: Used to style the website, including its colours, layout and responsive design.
* JavaScript: Used to add functionality and validate the booking form, display booking confirmation messages and implement the gallery lightbox.
* Visual Studio Code: Used as the development environment.
* Google Maps: Used to display an interactive map showing the location of Glow Up & Co.

4. Website Pages

The website consists of five main pages:

1. Home: Introduces Glow Up & Co.
2. About Us: Provides information about the beauty parlour.
3. Services: Displays the beauty services and price lists.
4. Gallery: Displays images related to the business.
5. Contact Us & Bookings: Provides contact information and a booking request form.

7. Website Functionality

The website includes the following interactive features:
* A booking form with required fields and date validation
* A JavaScript confirmation message after a valid booking request.
* An interactive Google Maps embed displaying the business location.
* A gallery lightbox that allows visitors to enlarge images and close the overlay.
* Enquiry form with HTML and JavaScript validation.
* Personalised confirmation message after a succesful enquiry submission.
* Enquiry form with HTML5 and JavaScript validation.
* Personalised confirmation message after a successful enquiry submission.
* General contact form with name, email, phone number, message type and message fields.
* JavaScript validation and personalised confirmation messages.
* Custom pink styling for the general contact form.
* Enquiry form connected to Formspree using AJAX (Fetch API).
* General contact form connected to Formspree using AJAX.
* Form submissions are delivered to the configured notification email.
* Successful and unsuccessful submission messages are displayed to users.

8. Booking Form

The contact page includes a booking request form. JavaScript is used to display a confirmation message after a valid submission and to prevent customers from selecting past booking dates.

Note: The current form displays a confirmation message in the browser. It does not yet send or store booking requests.

10. Project Status

The website is being developed as part of a web development assignment. Further improvements include testing, final documentation and deployment.

11. Performance and Security
- Implemented lazy loading for images to improve page loading performance.
- Added asynchronous image decoding.
- Compressed images to reduce file sizes.
- Used HTTPS for external form submissions through Formspree.
- Used HTML5 and JavaScript validation to check form inputs.
- Added hidden honeypot fields to the enquiry and contact forms to help reduce automated spam.
- Tested both forms after implementing spam protection.

12. Off-Page SEO and Local SEO

Glow Up & Co. is a fictional beauty parlour created for an academic web development project.

The following strategies are recommended to improve its online visibility:

- Backlinks: Build relationships with beauty blogs, local directories and relevant websites to obtain quality backlinks.
- Social Media: Promote the website through platforms such as Instagram and Facebook to reach potential customers.
- Local SEO: Use relevant location-based keywords, business information and local search terms to help nearby customers discover the business.
- Business Listings: Register the business on relevant online directories and Google Business Profile if it becomes an operating business.
